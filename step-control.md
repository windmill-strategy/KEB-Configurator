## Control Board Selection

The control board determines the communication interface and I/O capabilities of the drive. Select the board that matches your automation architecture.

### Options

**A1** — Basic analog/digital I/O control board. Provides standard analog speed reference inputs (0–10V, 4–20mA), digital inputs for start/stop/direction, and relay outputs for status signaling.

**A3** — Enhanced analog/digital I/O control board with additional input/output channels and expanded functionality for more complex standalone applications.

**K1** — CANopen fieldbus control board. Enables integration into CANopen-based automation networks with standardized communication profiles for drive control (CiA 402).

**P5-3 / P5-4 / P5-5** — PROFINET, EtherCAT, and EtherNet/IP fieldbus control boards respectively. These provide high-speed industrial Ethernet connectivity for integration into modern PLC-based automation systems.

### How to Choose

If your machine uses a PLC with a specific fieldbus protocol, select the matching control board. For simple applications without a PLC, the A1 or A3 analog/digital boards provide straightforward control via hardwired signals.
