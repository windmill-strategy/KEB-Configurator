## Selecting the Control / Safety Card

Select the control board that matches your automation architecture and safety requirements. Each card shows the full feature set for that option.

### Understanding the Tiers

**Basic** — Entry-level control for simple applications.

**Standard** — Mid-range covering common fieldbus protocols and safety functions. Available in Application and Pro variants.

**High** — Premium boards with widest protocol support and advanced safety.

### Quick Guide

For basic fieldbus with STO only, select **A1**. For broad protocol support, select **A3**. For full FSOE safety, select a **Pro** variant (K1-E, P5-3, P5-4, P5-5).
