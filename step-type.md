## Selecting the Drive Type

The drive type determines the core topology and feature set of the product platform.

### Available Types

**F6** is the standard frequency inverter platform. It provides comprehensive motor control with a wide range of configurable parameters for general-purpose industrial applications.

**S6** is the servo-grade variant designed for high-dynamic applications requiring precise positioning, speed regulation, and torque control. It is optimized for use with permanent magnet synchronous motors (PMSM).

### Which Type Do I Need?

Choose F6 for fans, pumps, conveyors, compressors, and other general industrial loads. Choose S6 for CNC machines, robotics, packaging machinery, and other applications requiring fast response and high positioning accuracy.
